🔍 API ENDPOINTS NOW AVAILABLE
─────────────────────────────

Upload:
POST /scans/upload
- Uploads image to Supabase Storage
- Creates scan record in database

Analyze:
POST /ml/infer/{scan_id}
- Runs ML model on scan
- Saves predictions to database
- Updates scan status

Get Predictions:
GET /scans/{scan_id}/predictions
- Returns all predictions for a scan
- Includes bounding boxes, confidence scores

Get Recommendations:
GET /recommendations/{scan_id}
- Returns treatment recommendations
- Includes drug contraindication checks

Log Correction:
POST /feedback/
- Logs dentist corrections
- For active learning

⚠️  TROUBLESHOOTING
──────────────────

Backend won't start?
→ Check: backend/.env has Supabase credentials
→ Try: brew reinstall python@3.11
→ Try: Recreate venv (see FIXES_APPLIED.md)

Upload fails?
→ Check: Predictions table exists in Supabase
→ Check: Backend is running
→ Check: Storage bucket 'xray-scans' exists and is PUBLIC

Analyze fails?
→ Check: Predictions table exists
→ Check: Backend logs for errors
→ Check: Scan has valid image_url

No predictions showing?
→ Run analyze first
→ Check: GET /scans/{scan_id}/predictions in API docs
→ Check: predictions table in Supabase has data

Bounding boxes not visible?
→ Toggle: "Show Bounding Boxes" checkbox
→ Check: Browser console (F12) for errors
→ Try: Click on a finding to highlight it
