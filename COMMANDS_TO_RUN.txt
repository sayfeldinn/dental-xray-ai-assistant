⚠️  IF BACKEND FAILS TO START (pip/venv issues):
───────────────────────────────────────────────

Option 1: Recreate virtual environment
cd backend
rm -rf .venv
/opt/homebrew/bin/python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload

Option 2: Manual package install (if pip has issues)
cd backend
/opt/homebrew/bin/python3.11 -m pip install --upgrade pip
/opt/homebrew/bin/python3.11 -m pip install fastapi uvicorn supabase python-dotenv python-jose[cryptography] passlib[bcrypt] python-multipart ultralytics pillow numpy opencv-python pydantic pydantic-settings
/opt/homebrew/bin/python3.11 -m uvicorn app.main:app --reload

Option 3: Check Python installation
brew reinstall python@3.11

🧪 HOW TO TEST FULL WORKFLOW:
────────────────────────────

1. Sign Up / Login
   → Create account at http://localhost:5173/signup

2. Add a Patient
   → Click "Patients" → "+ Add Patient"
   → Fill: Name, Age, Gender
   → Add Medical History: "Penicillin Allergy"
   → Add Allergies: "Amoxicillin"
   → Save

3. Upload X-Ray Scan
   → Click "X-Ray Scans" → "+ Upload New Scan"
   → Select patient
   → Choose image file
   → Upload

4. Analyze Scan
   → Click "🔍 Analyze" button
   → Wait for ML processing

5. Review Findings
   → Click "👁️ View Results"
   → See bounding boxes on X-ray
   → Mark findings as correct/incorrect
   → Click "Confirm All & Continue"

6. Confirm Treatment
   → Review treatment recommendations
   → See contraindication warnings
   → Click "Confirm Treatment Plan"
   → Done! ✅
